# Images locales

Déposez ici les images du site (formats conseillés : WebP ou AVIF, 1600 px de large maximum).

- `placeholder.svg` : image de secours affichée si une photo ne se charge pas.
- Pour remplacer une photo d'illustration Unsplash par une image locale, ouvrez
  `src/data/images.js` et remplacez `id: '…'` par `src: '/images/nom-du-fichier.webp'`.

⚠️ N'ajoutez que des images dont vous possédez les droits (photos produits, banques d'images
sous licence commerciale). Évitez les personnes identifiables et les marques sans autorisation.
